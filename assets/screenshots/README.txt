BBall Sideline IQ website — screenshots
================================

Drop your real app screenshots into THIS folder using the exact
filenames below. The website automatically shows them in place of the
built-in placeholder graphics — no code editing required. If a PNG is
missing, the matching placeholder SVG is shown instead, so the site
always looks complete.

FILES THE SITE LOOKS FOR
------------------------
  hero.png            -> Hero phone (top of page). Use your best "wow"
                         screen, e.g. the Live Game tracking screen.
                         Fallback: ph-hero.svg
  live-tracking.png   -> "Live courtside tracking" spotlight section.
                         e.g. Live Game / shot-confirm sheet.
                         Fallback: ph-live-tracking.svg
  shot-zones.png      -> "Shot zones & heatmaps" spotlight section.
                         e.g. the Shot Zones report tab.
                         Fallback: ph-shot-zones.svg

RECOMMENDED FORMAT
------------------
  - Portrait phone screenshots (the app's normal orientation).
  - Aspect ratio ~9:19.5 (e.g. 1170 x 2532 px, an iPhone screenshot).
    Any tall portrait image works; the device frame crops gently.
  - PNG, exported at full device resolution for crispness on retina
    screens. Keep each file under ~1.5 MB if possible (the page
    lazy-loads them, but smaller = faster).
  - No rounded corners / status bar needed — the site draws the phone
    frame around your screenshot.

HOW TO CAPTURE
--------------
  - iOS Simulator / device: press the screenshot shortcut in the app's
    normal (portrait) view.
  - Android emulator / device: use the camera icon in the emulator
    toolbar, or the device's screenshot gesture.

TIP
---
  Take the screenshots on a device with a clean, representative game
  (good numbers, a full bench) so the marketing screens look their best.
